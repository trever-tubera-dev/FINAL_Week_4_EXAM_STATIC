Welcome to STATIC

STATIC is a home for people who love alternative music — Midwest emo, shoegaze, nu-metal, pop-punk, and everything in between. Browse featured releases, search by artist or genre, jump straight to Spotify, and see what the community is spinning right now.

I built STATIC as my HCI class final project. I wanted a music site that feels like the old underground web — DIY, personal, a little loud — instead of another endless recommendation feed. Every page runs on semantic HTML, one shared set of design tokens, and plain JavaScript.
